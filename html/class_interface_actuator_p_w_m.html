◆ changeDutycycle() [1/2]

virtual void InterfaceActuatorPWM::changeDutycycle ( int )
pure virtual

Veranderd de dutycycle.

Veranderd de dutycycle, deze wordt in het object opgeslagen. Als de actuator aan staat wordt de dutycycle meteen ingeladen, anders blijft de actuator uit en wordt het alleen opgeslagen in het object voor als de actuator weer ingeschakeld wordt.

Parameters
int- Dutycycle, kan een waarde hebben van 0 t/m 100.

Wordt geïmplementeerd door LampPWM en LampPWM.
