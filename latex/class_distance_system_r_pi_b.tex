\doxysubsection{Gedetailleerde Beschrijving}
Zorgt dat de afstand wordt weergegeven. 

De aansturing van het display, dat berekend wordt op het hoofd \doxylink{class_distance_system}{Distance\+System} op RPiB, wordt door verstuurd op het adres van de displays die de afstand weergeven.

Daarnaast wordt inkomende afstanddata doorgestuurd naar RPiA om te verwerken.
